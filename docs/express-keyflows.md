# ลำดับคำสั่งคีย์ Express ที่ถอดจากคลิปตัวอย่าง

ถอดจากคลิปสอน AutoPilotX × Express 14 คลิป (บทที่ 1–7 และตัวอย่าง A–G) โดยตัดภาพทุกเฟรม แล้วติดตามช่องที่มีแถบสีเขียว
(ช่องที่เคอร์เซอร์อยู่ใน Express) ร่วมกับข้อความสถานะของโปรแกรมระหว่างรัน

> ตรวจซ้ำกับคลิปความละเอียดสูง (1280×720 / 1920×1080) แล้วสำหรับบทที่ 1–7 และตัวอย่าง A–G
> ช่อง *ประเภทราคา* เป็นช่องแบบเลือก (combobox) ไม่ขึ้นแถบสีเขียว แต่ Enter ต้องผ่านด้วย (เห็นกรอบโฟกัสในคลิป D)
> คลิปกดปุ่มเร็วมาก (ประมาณ 30 ms ต่อคำสั่ง)
> และลำดับช่องอาจต่างตามการตั้งค่า Express ของแต่ละบริษัท เทมเพลตจึงหยุดให้ตรวจก่อนกดบันทึกทุกเอกสาร

## ชนิดคำสั่งที่คลิปใช้ และคำสั่งที่ใช้แทนใน EX-AutoKey

| ในคลิป | ใช้แทนใน EX-AutoKey |
|---|---|
| กดคีย์ลัด (Hotkey) เช่น Alt+A, Alt+R | ขั้นตอน *กดปุ่ม* `%a`, `%r` |
| กดปุ่ม (Key) Enter, Escape | `{ENTER}`, `{ENTER 12}`, `{ESC}` |
| กรอกข้อมูลจาก CSV | ขั้นตอน *ช่องข้อมูล* |
| พิมพ์ข้อความ (Text) เช่น รหัสสินค้า `4100-01` | ขั้นตอน *ข้อความคงที่* |
| คลิกเมาส์ (ตำแหน่ง X/Y) | ยังไม่รองรับ ใช้ปุ่มคีย์บอร์ดแทน |
| หน่วงเวลา 30 ms ต่อคำสั่ง | *หน่วงต่อตัวอักษร* / *หน่วงต่อขั้นตอน* |
| หยุดฉุกเฉิน Ctrl+Shift+S | Ctrl+Shift+Q หรือลากเมาส์ไปมุมซ้ายบน |
| แบ่งส่วน Header / Item / Footer | ส่วนหัวเอกสาร / รายการ / ท้ายเอกสาร |
| เลือกแถวเริ่ม–ถึงแถว | *เฉพาะแถวที่ … ถึง …* |

## ปุ่มของ Express ที่เห็นในคลิป

- **Alt+A** เพิ่มเอกสารใหม่ เคอร์เซอร์จะเริ่มที่ช่อง *แผนก* แล้วกด Enter หนึ่งครั้งไปช่องเลขที่เอกสาร
- **Enter** ไปช่องถัดไป ลำดับคือ ช่องหัวเอกสาร → ช่องท้ายเอกสาร (สถานที่ส่งของ, หักส่วนลด, หักเงินมัดจำ, VAT) → ตารางรายการ
- ในตารางรายการ: **รหัส → คลัง → จำนวน → ราคาต่อหน่วย → ส่วนลด → บรรทัดถัดไป**
  (ขายเงินสดมีคอลัมน์ *จำนวนเงิน* ต่อจากส่วนลดอีกหนึ่งช่อง)
- **Esc** ที่บรรทัดรายการว่าง = จบรายการและบันทึกเอกสาร (คลิป A)
  บางคลิปกด Enter ที่บรรทัดว่างแล้ว Express บันทึกและขึ้นเอกสารใหม่ให้ (บทที่ 5)
- **Alt+R** เปิดหน้าต่างหมายเหตุท้ายบิล (บทที่ 2)
- แท็บ: **F8** รายการสินค้า, **Ctrl+F8** รายละเอียดอื่น, **F7** รายการรับ/จ่ายชำระ, **Ctrl+F7** รายการภาษีขาย/ซื้อ
- วันที่พิมพ์แบบ `วว/ดด/ปป` ปี พ.ศ. 2 หลัก เช่น `10/08/69`

## ลำดับช่องแต่ละหน้าจอ

`[ ]` คือช่องที่คลิปพิมพ์ค่าจากไฟล์ ช่องอื่นกด Enter ผ่าน

### ขายเงินเชื่อ (IV) — คลิป A, B
Alt+A → แผนก → [เลขที่เอกสาร] → [วันที่] → [รหัสลูกค้า] → Bill to → สาขา → ใบสั่งขาย → [อ้างอิง] →
เครดิต → ครบกำหนด → พนักงานขาย → เขตการขาย → ขนส่งโดย → ประเภทราคา → สถานที่ส่งของ → หักส่วนลด → หักเงินมัดจำ (รหัส) →
หักเงินมัดจำ (จำนวน) → VAT % → VAT (จำนวน) → [รหัสสินค้า] → คลัง (คลิป B พิมพ์) → [จำนวน] → [ราคาต่อหน่วย] → ส่วนลด →
บรรทัดถัดไป … → Esc

### ขายเงินสด (HS) — บทที่ 1–3
เหมือนขายเงินเชื่อ แต่ไม่มีเครดิต/ครบกำหนด และตารางมีคอลัมน์จำนวนเงิน
บทที่ 3 พิมพ์ `1` ในช่องประเภทราคา (1 = รวม VAT) ก่อน Enter ต่อไปตาราง
คลิปใช้ไฟล์แบบ 1 แถวต่อ 1 บิล มีคอลัมน์จำนวน/ราคาแยกตามสินค้า (เช่น `จำนวน/หน่วย-4100-01`) และพิมพ์รหัสสินค้าเป็นข้อความคงที่
ตอนจบกด Esc 2 ครั้ง → Alt+R → พิมพ์หมายเหตุ → Enter → คลิกตกลง

### ซื้อเงินสด (HP) — บทที่ 4–5
Alt+A → แผนก → [เลขที่] → [วันที่] → [รหัสผู้จำหน่าย] → Bill be → สาขา → อ้างถึงใบสั่งซื้อ → [เลขที่บิล] → [ลว.] →
หมายเหตุ → ขนส่งโดย → ประเภทราคา → หักส่วนลด → หักเงินมัดจำ ×2 → VAT ×2 → [รหัสบัญชี/สินค้า] → คลัง → จำนวน → [ราคา = ยอดก่อน VAT] → ส่วนลด →
บรรทัดถัดไป → Enter (บันทึกและขึ้นเอกสารใหม่) → [รหัสสาขา/แผนก]

### ซื้อเงินเชื่อ (RR) — บทที่ 6–7, คลิป D, E
Alt+A → แผนก → [เลขที่] → [วันที่] → [รหัสผู้จำหน่าย] → Bill be → สาขา → อ้างถึงใบสั่งซื้อ → [เลขที่บิล] → [ลว.] →
[หมายเหตุ] → เครดิต → ครบกำหนด → ขนส่งโดย → ประเภทราคา → หักส่วนลด → หักเงินมัดจำ ×2 → VAT ×2 → [รหัสสินค้า] → [คลัง] (คลิป E) →
[จำนวน] → [ราคาต่อหน่วย] → ส่วนลด → บรรทัดถัดไป … → Esc
บทที่ 7 ใช้ *เลขที่บิล* / *ลว.* เป็นเลขที่และวันที่ใบกำกับภาษีของผู้ขาย

### รับชำระหนี้ (RE) — คลิป C
Alt+A → แผนก → [เลขที่ใบเสร็จ] → [วันที่ใบเสร็จ] → [รหัสลูกค้า] → Bill to → สาขา → อ้างอิง → พนักงานขาย → วันที่รับชำระ →
Express เปิด **หน้าต่างเลือกเอกสารที่ต้องการรับชำระหนี้** (บิลค้างของลูกค้า มีช่องติ๊ก ปุ่ม *ทำงาน <F5>*, *ยกเลิก*, *ค้นหา*, *เลือกใหม่ <Tab>*)
→ ติ๊กบิล (บิลที่รับไม่เต็มจะมีหน้าต่าง *ป้อนยอดรับชำระ* ให้ใส่ยอด แล้วตกลง) → *ทำงาน <F5>* บิลเข้าตาราง
→ ตาราง **ชำระโดยอื่นๆ <F7>** เปิดรายการรหัสวิธีรับเงิน (QR เช็ครับ, CH รับเงินสด, S1/C1 เงินโอนเข้าบัญชี, TF ค่าธรรมเนียมการโอน,
VS บัตร Visa, DC ส่วนลดเงินสด, TX ภาษีถูกหัก ณ ที่จ่าย, EX กำไรขาดทุนจากอัตราแลกเปลี่ยน) → เลือก S1 → ยอดชำระ
→ หน้าต่าง *ป้อนรายละเอียดเพิ่มเติม* (เข้าบัญชี, หมายเหตุ) → ตกลง → บันทึก
แผงสถานะของคลิปนี้แสดงเพียงชื่อส่วน (Header/Footer) จึงยังไม่รู้ปุ่มที่ใช้ติ๊กและเลือกแน่ชัด เทมเพลตจึงหยุดให้ทำส่วนนี้เอง

### จ่ายชำระหนี้ (PS) — คลิป F
ลำดับคล้ายรับชำระหนี้: หัวใบจ่ายเงิน (เลขที่, วันที่, ผู้จำหน่าย, Bill be, สาขา, หมายเหตุ) → เลือกบิลที่จ่าย →
ตารางชำระโดยอื่นๆ <F7> → บันทึก

### บันทึกค่าใช้จ่ายอื่น + หัก ณ ที่จ่าย (OE) — คลิป G
คลิปนี้ความละเอียด 1280×720 อ่านข้อความสถานะได้ครบทุกคำสั่ง

หน้าบันทึกค่าใช้จ่าย:
Alt+A → แผนก → [เลขที่เอกสาร] → [วันที่] → [รหัสเจ้าหนี้] → Bill be → สาขา → เลขที่บิล → ลวท. → [คำอธิบาย] →
ประเภทราคา (พิมพ์ `0` = ไม่มี VAT) → VAT % → VAT → ดอกเบี้ยจ่าย → เงินสด → ชำระโดยอื่นๆ → ส่วนลดเงินสด →
ตาราง [รหัสบัญชีค่าใช้จ่าย] (คลิปพิมพ์ `5130-12` เป็นข้อความคงที่) → รายละเอียด → แผนก → [จำนวนเงินก่อนหักภาษี] → บรรทัดถัดไป

จากนั้นกด **Alt+A** เปิดหน้าต่าง *ป้อนรายละเอียดภาษีหัก ณ ที่จ่าย*:
[เล่มที่/เลขที่] → วันที่ออกหนังสือรับรอง → ยื่นภาษีรวมในงวดที่ → ยื่นเพิ่มเติม → วันที่เอกสารภายใน → แผนก → รหัสผู้ถูกหัก →
คำนำหน้าชื่อ → ชื่อ → ที่อยู่ → เลขประจำตัวผู้เสียภาษี → สาขา → ประเภทเงินได้ (กด **Ctrl+Delete** ล้างค่าเดิมแล้วพิมพ์ เช่น `ค่าขนส่ง`) →
[จำนวนเงินที่จะคำนวณภาษี] → [อัตราที่หัก] → เงื่อนไขการหักภาษี (พิมพ์ `1` = หักภาษี ณ ที่จ่าย) → Enter ผ่านช่องกลุ่ม 2,
หมวดภาษี (S03), ประกันสังคม, กองทุนสำรองเลี้ยงชีพ, กระทำการแทน → ปิดหน้าต่าง → Esc

ผลในคลิป: ค่าขนส่ง 32,100.00 หัก 1% = 321.00 ยอดจ่ายจริง (เงินสด) 31,779.00
Express ตั้งหมวดภาษีตามประเภทผู้รับเงินให้เอง (คลิปเป็น S03 = ภ.ง.ด.3 บุคคลธรรมดา)

## เทมเพลตใน EX-AutoKey ที่ปรับตามคลิป

| เทมเพลต | คลิปอ้างอิง | Enter ที่ใส่ไว้ |
|---|---|---|
| 01 ขายเงินสด (HS) | บทที่ 2–3 | หลังรหัสลูกค้า 8 ถึงประเภทราคา (พิมพ์ `1`), แล้ว 7 ถึงตาราง, หลังรหัสสินค้า 2, หลังราคา 3 |
| 02 ขายเงินเชื่อ (IV) | A | หลังรหัสลูกค้า 4 ถึงอ้างอิง, หลังอ้างอิง 13 ถึงตาราง, หลังรหัสสินค้า 2 |
| 03 ขายเงินเชื่อ ตัดสต๊อก (IV) | B | เหมือน 02 แต่พิมพ์คลังเอง |
| 04 รับชำระหนี้ (RE) | C | คีย์หัวใบเสร็จ แล้วหยุดให้เลือกบิล (แสดงเลขที่บิลและยอดจากไฟล์) |
| 05 ซื้อเงินสด (HP) | บทที่ 5 | หลังผู้จำหน่าย 4 ถึงเลขที่บิล, หลัง ลว. 9 ถึงตาราง |
| 06 ซื้อเงินเชื่อ (RR) | บทที่ 6, D | หลังผู้จำหน่าย 4, หลัง ลว. 11 ถึงตาราง |
| 07 ซื้อเงินเชื่อ มี VAT (RR) | บทที่ 7 | เหมือน 06 ใช้เลขที่/วันที่ใบกำกับภาษี |
| 08 ซื้อเงินเชื่อ รับเข้าสต๊อก (RR) | E | เหมือน 06 พิมพ์หมายเหตุ (หลังหมายเหตุ 10 ถึงตาราง) และคลังเอง |
| 09 จ่ายชำระหนี้ (PS) | F | คีย์หัวใบจ่ายเงิน แล้วหยุดให้เลือกบิล |
| 10 ค่าใช้จ่าย + หัก ณ ที่จ่าย (OE) | G | หลังผู้รับเงิน 5 ถึงคำอธิบาย, ประเภทราคา `0` แล้ว 7 ถึงตาราง, หน้าต่างภาษีหัก: หลังเลขที่ 12 ถึงประเภทเงินได้ แล้วหยุดให้กดตกลงเอง |

ทุกเทมเพลตเริ่มด้วย `Alt+A` + `Enter` และจบด้วย *หยุดรอผู้ใช้* ให้ตรวจหน้าจอ ตามด้วย `Esc` เพื่อบันทึก
เมื่อทดลองแล้วลำดับตรงกับเครื่องของคุณ ลบขั้นตอน *หยุดรอผู้ใช้* ออกได้ โปรแกรมจะคีย์และบันทึกต่อเนื่องเอง
ถ้าเครื่องของคุณมีช่องมากหรือน้อยกว่านี้ ให้แก้จำนวน Enter ในช่อง *กดหลังพิมพ์* เช่น `{ENTER 12}` เป็น `{ENTER 11}`
